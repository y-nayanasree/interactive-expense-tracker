
# SpendWise - Interactive Expense Tracker

SpendWise is a responsive browser-based expense tracking application that helps users record, manage, categorize and filter their daily expenses.

## Features

- Add new expenses with descriptions and amounts.
- Edit existing expense details.
- Delete unwanted transactions.
- Categorize expenses.
- Filter expenses by category.
- Filter expenses using start and end dates.
- Calculate total expenses automatically.
- Display highest individual expense.
- Show category-wise spending summary.
- Store expense records using LocalStorage.
- Responsive user interface for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Add expenses using the expense form.
5. Manage and filter transactions using the dashboard.

## Data Storage

The application uses browser LocalStorage to save expense records.

Saved expenses remain available after refreshing the page in the same browser.

## Deployment

The application can be deployed using GitHub Pages.
